# Terraform

## Commit Setting
```shell
terraform init
```

## Check Code
```shell
terraform plan
```

## Create Stack
```shell
terraform apply
```

## Delete Stack
```shell
terraform destroy
```

## Parallel Processing Create Stack
```shell
terraform apply --parallelism=30
```

## Auto Approve Create Stack
```shell
terraform apply --auto-approve
```

## Auto Approve & Parallel Processing Create Stack
```shell
terraform apply --auto-approve -parallelism=30
```
